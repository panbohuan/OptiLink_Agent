## 项目概述

OptiLink Agent 是一套面向夜间经济领域的智能分析系统，针对大学生夜间餐饮消费行为进行数据驱动的商业洞察。系统通过融合实地调研问卷数据与大语言模型的自然语言理解能力，实现了多维度消费行为分析、自动化数据可视化及智能决策支持。

### 核心能力

| 能力 | 说明 |
|------|------|
| 自然语言驱动的消费数据分析 | 用户通过日常对话方式查询调研数据，系统自动识别意图并返回结构化分析结果 |
| 自动化图表生成 | 支持饼图、柱状图、条形图、雷达图，根据问题关键词自动匹配最佳图表类型 |
| 基于真实调研数据的上下文检索增强 | 对话前自动检索调研数据中的相关统计信息，确保回答基于真实数据而非大模型幻觉 |
| 多轮对话上下文理解与历史记忆 | 维护最近20轮对话历史，支持连续提问和追问 |

## 功能说明

### 1. 智能对话分析

用户通过自然语言查询调研数据，系统自动识别意图并返回结构化分析结果。

**示例输入：**

```
生活费1500-2000元的学生夜间消费偏好是什么？
```

**系统输出：**

```
根据优联团队的市场调研报告，生活费1500-2000元的学生中：
- 主要消费品类：烧烤（38%）、奶茶（27%）、炸鸡（18%）
- 平均客单价：28-35元
- 消费高峰时段：21:00-23:00
- 主要决策渠道：小红书（52%）、抖音（31%）
```

### 2. 自动化数据可视化

支持关键词触发的图表生成，系统自动识别问题并匹配最佳图表类型。

| 命令 | 图表类型 | 适用场景 |
|------|----------|----------|
| `/chart 生活费分布` | 柱状图 | 展示数量分布 |
| `/chart 性别比例` | 饼图 | 展示占比关系 |
| `/chart 种草渠道排名` | 条形图 | 展示排序对比 |
| `/chart 时段偏好` | 雷达图 | 展示多维度特征 |

**示例：**

```
你: /chart 生活费分布
```

系统自动生成柱状图并保存至 `reports/` 目录，同时打开图片供用户查看。

### 3. 系统命令

| 命令 | 功能 |
|------|------|
| `/stats` | 查看系统运行状态（对话轮次、已生成图表数、数据状态） |
| `/reset` | 清空对话历史，重置上下文 |
| `/clear` | 清屏 |
| `/help` | 显示帮助信息 |
| `/exit` | 退出系统 |

### 4. 意图识别与问题分类

系统内置关键词匹配引擎，自动识别用户问题类型：

| 问题类型 | 触发关键词示例 |
|----------|----------------|
| 生活费分析 | 生活费、月均、可支配 |
| 消费频率 | 频率、每周、次数 |
| 消费时段 | 时段、20:00、深夜 |
| 消费动机 | 动机、原因、社交、解压 |
| 种草渠道 | 抖音、小红书、美团、种草 |

## 核心算法

### 意图识别与问题分类

系统通过关键词匹配与规则引擎实现问题分类：

```python
QUESTION_KEYWORDS = {
    "生活费": ["生活费", "月均", "可支配"],
    "消费频率": ["频率", "每周", "次数"],
    "消费时段": ["时段", "20:00", "22:00", "深夜"],
    "消费动机": ["动机", "原因", "社交", "解压"],
    "种草渠道": ["抖音", "小红书", "美团", "种草"],
}
```

### 图表类型自适应匹配

```python
CHART_KEYWORDS_MAP = {
    "饼图": ["比例", "占比", "分布", "性别", "年级"],
    "柱状图": ["频率", "次数", "生活费", "客单价"],
    "条形图": ["渠道", "排名", "对比", "最常"],
    "雷达图": ["时段", "偏好", "多维度"],
}
```

### 上下文检索增强

系统在对话前自动检索调研数据中的相关统计信息，融入提示词上下文：

```python
def _build_messages_with_history(self, message: str) -> List[Dict]:
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    for entry in self.conversation_history[-self.max_history_length:]:
        messages.append({"role": entry["role"], "content": entry["content"]})
    messages.append({"role": "user", "content": message})
    return messages
```

### 图表生成流程

1. 用户输入问题（如 `/chart 生活费分布`）
2. 系统匹配问题类型 → 确定分析维度
3. 从调研数据中提取对应统计值
4. 根据关键词匹配最佳图表类型
5. 调用 Matplotlib 渲染图表
6. 保存至 `reports/` 目录并自动打开
